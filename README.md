## Adding more photos later

1. Open the `assets` folder in GitHub.
2. Select **Add file → Upload files**.
3. Upload a compressed JPG or WebP.
4. Edit `index.html`.
5. Duplicate one of the existing `<figure class="gallery-item">...</figure>` blocks.
6. Change the filename, alt text, category, and title.

Recommended website image export:

- JPG quality: 75–85
- Long edge: 2,000–2,500 px
- Target size: under 1 MB when practical
- Use lowercase filenames with hyphens and no spaces
